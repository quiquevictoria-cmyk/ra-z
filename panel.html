Este panel lee tus datos de GoatCounter. Necesita una clave de API de solo lectura, que se guarda únicamente en este navegador.

  1. En tu panel de GoatCounter pulsa tu usuario arriba (quiquevictoria@) y entra en API.
  2. Pulsa Create new token, ponle un nombre (por ejemplo «Panel») y marca solo Read statistics.
  3. Copia la clave y pégala aquí.
